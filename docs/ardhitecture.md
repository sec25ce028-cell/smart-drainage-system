# System Architecture

## Project
Smart Drainage System for Sustainable Development

## Objective
To monitor drainage water levels, detect potential blockages, and support timely waste removal.

## Main Components
1. Water-level sensor
2. Blockage-detection sensor
3. Microcontroller
4. Alert mechanism
5. Waste collection basket

## Working Principle
The sensors collect drainage data and send readings to the microcontroller. The controller checks the readings for high water levels or possible blockages. When a problem is detected, an alert can be generated so that appropriate action can be taken.

## Expected Benefits
- Early detection of drainage problems
- Reduced water stagnation
- Better plastic waste management
- Improved urban cleanliness

## Note
The final implementation depends on the sensors and hardware used in the working prototype.
